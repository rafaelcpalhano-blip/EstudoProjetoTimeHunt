# Time Hunt

Time Hunt é um projeto 2D desenvolvido na Unity 6.3 LTS com foco no estudo de desenvolvimento de jogos e na evolução prática de habilidades em programação, level design, animação e criação de interfaces.

O projeto está em desenvolvimento e funciona como um espaço para experimentar técnicas, organizar aprendizados e construir um portfólio de gamedev.

## Estado atual

Até o momento, o projeto conta com:

- estrutura inicial da primeira fase com Tilemaps em diferentes camadas;
- composição visual com sensação de profundidade e ambientação;
- movimentação do personagem;
- salto e salto duplo;
- dash com tempo de recarga;
- ataque principal com indicador de recarga;
- interface de gameplay com barra de vida e indicadores de habilidades;
- colisores e Physics Shapes configurados para o cenário.

Novas mecânicas, melhorias visuais e informações serão adicionadas conforme o desenvolvimento avançar.
